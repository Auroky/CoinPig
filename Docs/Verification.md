## 复现

使用 README 中的命令运行。场景检查用 `--verify`，截图可加 `--capture-dir`。自动策略模拟时间快于实际时间，用于检查流程，不代表玩家能以同样速度通关。

人工演示可按以下顺序：开始游戏；只移动鼠标，确认锤子自动击碎小猪；移出桌面检查停止；观察一锤只扣一点体力；查看租约确认暂停；收工尝试余额不足的购买；第二天提前收工展示破产；另开一局正常经营完成全部五笔账单。

## 当前限制

- 尚未由人完整试玩并评估经济难度。自动策略通过不代表对新手公平，也不是最佳策略证明。
- 没有存档、触屏适配或独立导出的发行版；当前通过 Godot .NET 工程运行。
- 尚无 CoinPig 的 3D 版，未验证跨维度一致性，也未产生实际 CCR。
- 各成员仍需对代码作独立解释和评审，并准备自己的反思。

## 自动挥锤与初始猪群

初始配置调整为两只陶瓷猪，移除主菜单的放大展示猪。场景检查增加：无需鼠标按键即可命中；光标不动时按恢复节奏连续挥锤；指针在桌外和暂停时不扣体力；开始或恢复营业不会把菜单操作位置当作自动落锤目标。

两只猪的完整经营检查采用等待双碎机会、预留下一期租金、优先购买收益和体力技能的策略，已走通十天租约；旧的八只猪购买策略未直接沿用。此结果证明存在可行操作路径，不代表人工难度已完成平衡。
