# CoinPig 还款日

AP6412 路线 B 的 2D 基础版候选：在十天内砸碎移动的储金猪赚钱，购买升级并支付五期租金。

目前完成可玩的 2D 版本。尚未冻结 `2d-baseline` 标签，也尚未开始本项目的 3D 转换。先进行小组试玩与设计确认，再冻结 2D 基线；此后保留标签不变，用实际后续提交说明 3D 改动。

## 运行

- Godot **4.7.2 .NET**，C#，.NET SDK **8.0**。普通非 .NET 版 Godot 不能运行 C# 工程。
- 在 Godot 项目管理器导入 `project.godot`，点击构建，再按 F6/F5 运行。
- 当前电脑可双击 `开始游戏.lnk`。该快捷方式使用本机 Godot 安装路径，换电脑后请用上一种方式。
- 源码构建：`dotnet build CoinPig.csproj`。首次构建可能需要访问 NuGet 下载 Godot SDK。
- 默认全屏；F11 切换窗口，逻辑基准 1600×900，按实际宽高比扩展；中文优先使用系统微软雅黑，其次 Noto Sans CJK SC。Linux 等环境请安装中文字体。
- 绘画、颗粒和音效由代码生成，不依赖外部下载素材。

## 操作和规则

鼠标移动瞄准，锤子自动连续挥动，无需点击；每锤有 0.19 秒蓄力和短暂恢复。每锤消耗 1 点体力，即使没有命中；一锤可以命中多只。将鼠标移出桌面后不再开始新的挥锤，已经蓄力的这一锤仍会落下。Esc 暂停/返回，E 提前收工，B 查看账单，F11 切换全屏。查看租约、打开说明或窗口失焦会暂停营业。

以下是猪种配置；初始只生成陶瓷猪。

| 猪种 | 耐久 | 击碎奖励 | 移速倍率 |
|---|---:|---:|---:|
| 陶瓷猪 | 1 | ¥2 | 1.00 |
| 铁皮猪 | 3 | ¥6 | 0.65 |
| 金鼻猪 | 1 | ¥4 | 1.50 |

默认猪群为两只普通陶瓷猪，沿相向轨迹移动，击碎后重生。其他猪种数据仍保留，但不加入初始猪群。每个工作日初始体力 12，可通过装备、技能和奖励增加；没有时间限制。耗尽体力自动收工，也可确认后提前收工。

第 2、4、6、8、10 天的租金依次为 ¥28、¥56、¥84、¥115、¥136。到期当天收工时自动交租，余额不足则破产；结清最后一期即获胜。胜利后可继续无尽经营，没有新账单。未到最后一期的成功交租提供三选一能力。商店、技能和房租使用同一钱包。

## 验证

纯规则检查不依赖 Godot：

```powershell
dotnet run --project Tests/CoreTests.csproj
```

实际场景自动检查（将 `godot` 换成自己的 Godot .NET 可执行文件）：

```powershell
godot --headless --path . -- --verify
godot --path . -- --verify --capture-dir Tests/results/captures
```

自动场景检查通过实际按钮、相同的落锤入口与更新流程运行；不注入金币。它覆盖正常经营、失败、十天通关和无尽模式。自动策略的通关结果不是人类难度或游戏平衡的证明。详见 [验证记录](Docs/Verification.md)。
